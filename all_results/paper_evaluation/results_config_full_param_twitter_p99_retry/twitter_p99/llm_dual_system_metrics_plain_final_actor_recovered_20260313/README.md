# Recovered Twitter/System histories

This directory contains all five measured Twitter/System histories from
March 13, 2026. They were recovered byte-for-byte from the misplaced-result
backup at:

`results_config_full_param_tpcc_hi_p99_20260306_080130_retry/tpcc_hi_p99/llm_dual_system_metrics_plain_final_actor copy/`

Each JSON file identifies `twitter` as its configured benchmark. Plot 2 prefers
this directory for the `twitter_p99` System series. These measurements replace
the former plotting-code substitution that added five percentage points to
the Twitter IPC result; no history is omitted.
